# 검증 범위

## 게임 화면 확인

게임 실행은 제작자가 직접 확인했습니다. 기존 부팅·메뉴·경기·커리어 초반, 선수·심판·오프라인 문구와 한글 입력·저장·재실행 후 재로드 확인을 유지합니다.
v1.01에서는 커리어 연습·튜토리얼의 양쪽 이름, 세션 제목·진행도와 이름표 겹침 해소, 대기 화면 이름을 확인했습니다. 로딩 문구는 앞선 경기 진입·PRIDE 로딩 확인과 실제 폭 갱신 기록을 기준으로 합니다.
커리어 전체 진행과 모든 모드·선수·장면을 전수 플레이한 것은 아닙니다. 원문 비교환경에서 새 선수도 검은 사진칸을 보인다는 사용자 확인에 따라 이 항목은 보류합니다.

## 설치 도구

Windows PowerShell 5.1 / .NET Framework와 별도 파일 복사본에서 27개 검사를 통과했습니다.

- 신규 설치·중복 설치·검사·복원·중복 복원
- v1.0 beta 설치 상태에서 v1.01 직접 업데이트
- 이전 버전 백업 보존, 1.01→1.0→한글패치 전 상태 단계 복원
- 다른 판본·다른 수정본·알 수 없는 보조 파일과 손상된 일반·업데이트 자료 거부
- 수정된 파일·손상된 백업의 강제 덮어쓰기 거부
- 실제 파일 교체 실패 시 자동 원상복구
- 한글·공백·대괄호·괄호·앰퍼샌드 경로와 설정·저장·기존 Reborn 패치 보존
- 현재 시험본은 검사 모드로만 확인
- ZIP CRC·전체 내부 파일 해시·최종 ZIP SHA-256 확인

패키지는 게임·Reborn 본체·에뮬레이터·개인 설정·저장을 제공하지 않습니다. 설치기는 지원 판본을 파일 해시로 확인합니다.
