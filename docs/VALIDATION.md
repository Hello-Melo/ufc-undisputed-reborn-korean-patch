# 검증 범위

## 실제 게임 확인

게임 실행은 제작자가 직접 확인했습니다. 부팅·메뉴·경기·커리어 초반, 이름·심판·오프라인 문구, 한글 이름 입력·저장·종료 후 재실행·재로드를 확인했습니다.

최신 수정에서 경기 진입과 PRIDE 로딩을 확인했습니다. 실제 폭 갱신 기록 9건의 변경량·진행 거리 계산을 대조했고, 다음 문장 좌표는 해당 기록값을 적용 명령으로 재생해 검증했습니다. 다음 좌표의 직접 실행 로그와 코드 재생 검증은 구분합니다.

커리어 전체 진행과 모든 선수·장면을 전수 플레이한 것은 아닙니다. 최근 개별 소개 정보와 제작자 표시는 적용·파일 검사와 장면별 사용자 확인 범위를 구분합니다.

## 설치 도구

Windows PowerShell 5.1 / .NET Framework 환경의 별도 복사본에서 18개 검사를 통과했습니다.

- 설치 전 검사, 최초 설치, 같은 버전 재설치, 설치 후 검사
- 설치 전 상태로 복원, 중복 복원, 복원 후 재설치
- 다른 판본·다른 수정본·알 수 없는 보조 패치·손상된 패치 자료 거부
- 설치 뒤 변경된 파일 및 손상된 백업의 강제 덮어쓰기 거부
- 파일 교체 도중 실제 실패를 발생시켜 자동 원상복구 확인
- 한글·공백·대괄호·괄호·앰퍼샌드가 포함된 경로 확인
- 설정·저장·기존 Reborn 보조 패치 보존 확인
- ZIP 내부 CRC·전체 포함 파일 해시·최종 ZIP SHA-256 확인

게임·Reborn 본체·에뮬레이터를 설치하거나 함께 배포하는 도구가 아닙니다. 지원 판본은 설치기가 파일 해시로 검사합니다.
