# 검증 범위

## 게임 화면 확인

게임 실행은 사용자가 직접 확인했습니다. 부팅·메뉴·경기·커리어 초반, 한글 이름 입력·저장·재로드와 커리어 연습·튜토리얼 표시 확인을 기준으로 합니다.
이번 수정본은 커리어 한글 표시·뉴스 번역·선수 이미지 생성 및 저장 수정 후 정상 동작을 확인했습니다. fast 옵션에서 경기 프레임 회복과 사진 정상 표시를 사용자가 확인했습니다.
커리어 전체 진행과 모든 모드·선수·장면을 전수 플레이한 것은 아닙니다.

## 설치 도구

Windows PowerShell 5.1 / .NET Framework와 별도 파일 복사본에서 64개 검사를 통과했습니다.

- 신규 설치·중복 설치·검사·복원·중복 복원
- 기존 v1.0 beta 및 이전 v1.01에서 수정본으로 업데이트
- 이전 백업 보존과 세 단계 복원을 통한 한글패치 전 상태 복귀
- 다른 판본·다른 수정본·알 수 없는 보조 파일·손상된 자료 거부
- 설치 후 수정된 파일·설정 및 손상된 백업의 강제 덮어쓰기 거부
- 파일 또는 설정 교체가 실패할 때 전체 원상복구
- 이미지 저장 옵션 생성·변경·복원 및 그 외 설정·저장·기존 모드 패치 보존
- 한글·공백·대괄호·괄호·앰퍼샌드가 포함된 경로
- 현재 성공 시험본은 읽기 전용 검사로만 확인
- ZIP CRC·내부 파일 해시·최종 ZIP SHA-256 확인

설치기는 Reborn 게임별 GPU.readback_resolve 옵션만 fast로 설정하며, 기존 설정은 백업하고 복원할 수 있습니다.
게임·Reborn 본체·에뮬레이터·개인 설정 파일·저장 데이터는 배포하지 않습니다.
