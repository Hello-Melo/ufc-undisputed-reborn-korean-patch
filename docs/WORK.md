# 작업 내용

## v1.01 변경 사항

- 커리어·연습·튜토리얼 경기의 한글 이름 표시와 한국 생성 선수의 성+이름 순서 보완
- 커리어 튜토리얼 대기·결과 화면의 이름을 한 줄로 정리
- 튜토리얼 세션 제목·배경·진행도와 경기 HUD의 겹침 해소
- 이름의 잘못된 그림 마스크와 흰색 그림자 제거, 버튼 아이콘 보존
- 커리어 화면 전환·튜토리얼 진입에 필요한 한글 표시 관련 메모리 처리 보완
- 기존 v1.0 beta에서 바로 업데이트, 설치 직전 버전으로 복원 지원


## 적용 범위

- 공통 메뉴·설정·가이드·경기·연습·튜토리얼·기록·커리어 문구 한글화
- 상점·대진·해금 조건·경기장·체육관·인물 관련 오프라인 문구 정리
- 확인된 실제 선수 이름과 심판 표기, 커리어 이름·성·별명 후보 440개 한글화
- 선수 선택·입장·경기 중·경기 후 이름 표시와 글꼴 선명도·기준선 보완
- 자음·모음 조합 한글 이름 입력, 쌍자음·복합모음·겹받침·지우기 지원
- 현재 Reborn 선수표에서 사용이 확인된 DLC 국가·지역·체육관 문구 31개 한글화
- 시작 화면에 한국어 패치 · Melo 제작자 표시
- 로딩 화면의 글꼴 전환 시 문장 폭·다음 시작 좌표·남은 이동 거리 동기화

## 기준

- Undisputed Reborn 1.1 / Xbox 360 / 타이틀 ID 5451087D
- 글꼴: Pretendard Bold v1.3.9 기반
- Reborn의 PRIDE, 선수 등록·능력치·모델·음성 연결과 화면별 원래 크기 변화 유지
- 이름 한 칸의 기존 저장 한도는 UTF-8 24바이트로, 한글만 입력하면 최대 8자

## 확인 범위

- 사용자가 부팅·메뉴·경기·커리어 초반, 이름 표시·심판·오프라인 추가 문구를 확인했습니다.
- 한글 이름 입력·저장·게임 종료 후 재실행·재로드를 확인했습니다.
- 기존 로딩 수정에서 경기 진입과 PRIDE 로딩을 확인했고 실제 폭 갱신 로그 9건을 검증했습니다.
- v1.01에서 커리어 튜토리얼 경기 이름·세션 제목·진행도와 대기 화면 이름을 사용자가 확인했습니다.
- 설치·중복 설치·복원 및 잘못된 입력/손상 자료 거부는 별도 검증용 복사본에서 검사했습니다.
- 커리어 전체 진행과 모든 선수·장면을 전수 플레이한 것은 아닙니다.

## 유지·제외

- 온라인 전용 번역, 미확정 선수·관계자 등록번호 53개는 제외합니다.
- 실제 사용이 확인되지 않은 DLC 원문·브랜드·약어·음악 제목·기존 제작진 표기를 유지합니다.
- 영어 음성·해설·영상 음성은 변경하지 않습니다. 영상 전체의 신규 자막 제작은 포함하지 않습니다.
- 입장 장면의 일부 어깨·팔 이음새 현상은 패치 전에도 확인됐으며 이 패치의 수정 범위가 아닙니다.
- 커리어 대기 화면의 검은 선수 사진칸은 원문 비교환경에서 새 선수로도 재현됐으며 이번 수정 범위에서 제외합니다. 원인을 확정한 것은 아닙니다.
- 일부 긴 문구·커리어 후반·개별 소개 정보는 장면별 추가 검수가 필요할 수 있습니다.

이 배포물에는 게임/Reborn 본체, Xenia 실행 파일, 개인 설정·저장, 비교용 진단본이나 배경 미리보기가 없습니다.
