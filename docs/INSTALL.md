# 설치 안내

## 준비

- Windows / Xbox 360용 Undisputed Reborn 1.1 / Xenia가 필요합니다.
- 게임과 Reborn 모드는 따로 준비해야 합니다. PS3·RPCS3·Forever용이 아닙니다.
- ZIP을 모두 압축 해제하고 Xenia를 완전히 종료하세요.

## 설치

1. 설치.cmd를 실행합니다.
2. Reborn 게임과 Xenia가 들어 있는 폴더를 선택합니다.
   두 폴더를 자동으로 찾지 못하면 게임 폴더와 Xenia 폴더를 각각 선택합니다.
3. 설치 완료 메시지를 확인하고 기존 Reborn 실행 방법으로 실행합니다.

- 기존 v1.0 beta 사용자도 같은 설치.cmd로 바로 업데이트할 수 있습니다. 기존 백업은 유지됩니다.

## 검사와 복원

- 검사.cmd: 지원 판본과 설치 상태만 확인합니다.
- 복원.cmd: 같은 Reborn 폴더를 선택하면 가장 최근 설치 직전 상태로 복원합니다.
- 1.0에서 업데이트했다면 첫 복원은 1.0으로, 다시 복원하면 이전 1.0 설치 백업을 이용해 한글패치 전 상태로 돌아갑니다.
- 백업은 게임 폴더 안의 Melo_Reborn_KO_Backups에 보관됩니다. 복원할 때까지 삭제하지 마세요.
- 같은 패치를 다시 설치하면 기존 백업을 유지하고 중복 적용하지 않습니다.
- 설치 뒤 다른 수정본으로 바뀐 파일은 덮어쓰거나 강제로 복원하지 않습니다.

## 설치가 중단되는 경우

- 다른 판본/수정본: 수정되지 않은 Reborn 1.1 복사본에 설치하세요.
- 손상된 배포 파일: ZIP을 다시 받아 새 폴더에 모두 압축 해제하세요.
- 실행 중/읽기 전용 파일: Xenia를 종료하고 파일 접근 상태를 확인하세요.
- 한글이 표시되지 않으면 설치 때 선택한 Xenia로 실행했는지, 기존 Xenia의 패치 적용 기능이 켜져 있는지 확인하세요.

설치기는 실행 설정, 그래픽 옵션, 키 설정, 캐시, 저장 데이터와 기존 Reborn 패치를 변경하지 않습니다.
일반적인 설치에는 관리자 권한이나 별도 Python 설치가 필요하지 않습니다.
