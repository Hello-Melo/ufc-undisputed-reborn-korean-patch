# 설치 안내

준비
- Windows / Xbox 360용 Undisputed Reborn 1.1 / Xenia가 필요합니다.
- 게임과 Reborn 모드는 별도로 준비하세요. PS3·RPCS3·Forever용이 아닙니다.
- ZIP을 모두 압축 해제하고 Xenia를 완전히 종료하세요.

설치
1. 설치.cmd를 실행합니다.
2. Reborn 게임과 Xenia가 들어 있는 폴더를 선택합니다.
   자동으로 찾지 못하면 게임 폴더와 Xenia 폴더를 각각 선택합니다.
3. 설치 완료 후 기존 Reborn 실행 방법으로 실행합니다.
- 기존 v1.0 beta 및 v1.01도 같은 설치.cmd로 업데이트할 수 있습니다.
- 설치기는 Reborn 게임별 이미지 저장 옵션(GPU.readback_resolve = fast)만 설정합니다.
  전역 그래픽 설정·해상도·키 설정·기존 모드 패치·저장 데이터는 유지합니다.
- 이전에 선수 이미지가 비어 있거나 깨졌다면 커리어의 내 선수 → 외모 편집에서
  저장 후 계속하기로 이미지를 다시 생성하세요. 새 선수를 만들 필요는 없습니다.

검사와 복원
- 검사.cmd: 판본·패치·이미지 저장 옵션을 검사하며 파일을 바꾸지 않습니다.
- 복원.cmd: 가장 최근 설치 직전의 파일과 이미지 저장 옵션으로 되돌립니다.
- 이전 버전에서 업데이트했다면 복원을 반복해 설치 전 단계로 돌아갈 수 있습니다.
- 백업은 게임 폴더의 Melo_Reborn_KO_Backups에 보관합니다. 복원 전까지 유지하세요.
- 이미 같은 패치와 옵션이 적용돼 있으면 기존 백업을 유지하고 중복 적용하지 않습니다.
- 설치 후 수정된 파일이나 설정은 강제로 덮어쓰거나 복원하지 않습니다.

설치가 중단되는 경우
- 다른 판본/수정본: 지원하는 Reborn 1.1 복사본을 선택하세요.
- 손상된 배포 파일: ZIP을 다시 받아 새 폴더에 모두 압축 해제하세요.
- 실행 중/읽기 전용 파일: Xenia를 종료하고 파일 접근 상태를 확인하세요.
- 한글이 안 나오면 설치 때 선택한 Xenia로 실행했는지, 패치 적용 기능이 켜져 있는지 확인하세요.

개인 설정 파일과 저장 데이터는 배포물에 포함하지 않습니다.
일반 설치에는 관리자 권한이나 별도 Python 설치가 필요하지 않습니다.
